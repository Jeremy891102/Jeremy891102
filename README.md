## Selected work

### [Clinical Risk Prediction Benchmark](https://github.com/Jeremy891102/Clinical-Risk-Prediction-on-Small-Medical-Datasets)

**Objective:** Compare a tabular foundation model with classical ML on small clinical datasets.

**Result:** TabPFN has the lowest mean Brier score on all 5 datasets; AUROC results vary by dataset.

**My work:** Independently built the data pipeline, nested-CV benchmark, and result analysis.
